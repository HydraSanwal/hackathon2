# Formatting & Compilation Sub-Agent

## When to Use
- After chapters are polished and ready
- User wants final book in readable format

## How This Agent Works
1. Receives polished chapters from Editing Sub-Agent
2. Applies consistent formatting (titles, headings, spacing)
3. Combines chapters into a single book document
4. Ensures table of contents, chapter numbering, and metadata are correct
5. Returns fully formatted book ready for export or submission

## Output
- Complete book document with proper formatting and structure
