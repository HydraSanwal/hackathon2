# Research Sub-Agent

## When to Use
- User provides a book title or topic
- Chapter summaries or factual references are needed

## How This Agent Works
1. Receives book title, genre, and target audience
2. Researches themes, topics, and references relevant to the book
3. Generates 3–6 sentence chapter summaries for each chapter
4. Returns chapter summaries and research notes to Main Orchestrator

## Output
- Chapter summaries ready for Writing Sub-Agent
- Research notes and references for context
