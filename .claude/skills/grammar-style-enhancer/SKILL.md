# Grammar & Style Enhancer Skill

## When to Use This Skill
- User provides text to improve, polish, or rewrite  
- User wants cleaner writing, better flow, or corrected grammar  
- User asks for “fix this paragraph” or “make this sound professional”

## How This Skill Works

1. **Check grammar**: Fix mistakes, punctuation, and sentence structure  
2. **Improve clarity**: Remove unnecessary words, rewrite confusing parts  
3. **Enhance style**: Adjust tone, vocabulary, and consistency  
4. **Strengthen flow**: Connect ideas smoothly  
5. **Preserve meaning**: Keep original message but improve delivery  

## Output Format

Provide:
- **Corrected Version**: Clean rewritten text  
- **List of Improvements**: 3–6 bullet points  
- **Optional Enhanced Style Version**: More expressive rewrite (if needed)

## Example

**Input:** “He walk slowly towards the door, thinking of what happen yesterday.”

**Output:**
- **Corrected Version:** “He walked slowly toward the door, thinking about what had happened yesterday.”  
- **Improvements:**  
  - Fixed verb tense errors  
  - Corrected prepositions  
  - Improved readability  
  - Cleaned sentence flow
