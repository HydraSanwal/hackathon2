# Chapter Auto-Writer Skill

## When to Use This Skill
- User provides a chapter title and summary  
- User wants the full text of the chapter written automatically  
- User asks “write this chapter” or “expand this outline”

## How This Skill Works

1. **Read outline and summary**: Understand the chapter goals  
2. **Maintain style & tone**: Use book’s overall voice  
3. **Generate paragraphs**: Write 3–6 coherent paragraphs per chapter  
4. **Ensure flow**: Make sure events and dialogue match the outline  
5. **Preserve consistency**: Characters, timelines, and style remain stable

## Output Format

Provide:
- **Chapter Title**: As given in input  
- **Chapter Text**: 3–6 paragraphs fully written  
- **Optional Notes**: Any suggestions or enhancements for next chapters

## Example

**Input:**  
Chapter Title: “The Hidden Map”  
Summary: “The hero discovers a mysterious map in an ancient temple that sets them on their quest.”

**Output:**  
- **Chapter Title:** The Hidden Map  
- **Chapter Text:**  
  The temple smelled of dust and ancient stone. Arham’s fingers traced the worn engravings as a faint glow caught his eye…  
  Paragraph 2…  
  Paragraph 3…  
- **Optional Notes:** Consider adding minor dialogue between Arham and his mentor for more engagement.
