# Chapter Outline Generator Skill

## When to Use This Skill
- User wants a book outline, chapter breakdown, or structure
- User gives title, theme, genre, or number of chapters
- User asks for “plan my book” or “make chapter list”

## How This Skill Works

1. **Analyze concept**: Identify theme, genre, tone, and target audience  
2. **Create story arc**: Build a clear beginning, middle, and end  
3. **Generate chapter list**: 5–20 chapters depending on complexity  
4. **Write summaries**: Each chapter gets a 2–3 sentence summary  
5. **Ensure flow**: Make sure the narrative progresses logically  

## Output Format

Provide:
- **Book Summary**: 3–4 sentence overview  
- **Genre & Tone**: One short line  
- **Chapter Titles**: Numbered list  
- **Chapter Summaries**: 2–3 sentences each  

## Example

**Input:** “Create a fantasy book outline titled *The Lost Kingdom*, 12 chapters.”

**Output:**
- **Book Summary:** A young warrior discovers a forgotten kingdom hidden in the clouds…  
- **Genre & Tone:** Epic fantasy, adventurous, dramatic  
- **Chapters:**
  1. The Hidden Map  
  2. A Call to Destiny  
  3. Across the Misty Forest  
  ...  
- **Chapter Summaries:**  
  1. *The Hidden Map*: The hero discovers a glowing map inside an old temple…
