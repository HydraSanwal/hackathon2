# Physical AI & Humanoid Robotics: From Theory to Action

This repository contains the educational book "Physical AI & Humanoid Robotics: From Theory to Action", a comprehensive guide covering the 4 core modules of Physical AI and Humanoid Robotics.

## Modules

1. **Module 1: ROS 2 Robotic Nervous System** - Introduction to Robot Operating System 2, nodes, topics, services, and communication patterns
2. **Module 2: Digital Twin (Gazebo & Unity)** - Simulation environments and digital twin concepts using Gazebo and Unity
3. **Module 3: NVIDIA Isaac AI-Robot Brain** - AI integration and robot control using NVIDIA Isaac platform
4. **Module 4: Vision-Language-Action (VLA)** - Advanced integration of vision, language, and action systems

## Development

This site is built with [Docusaurus](https://docusaurus.io/), a modern static website generator.

### Installation

```bash
npm install
```

### Local Development

```bash
npm start
```

This command starts a local development server and opens up a browser window. Most changes are reflected live without having to restart the server.

### Build

```bash
npm run build
```

This command generates static content into the `build` directory and can be served using any static contents hosting service.

### Deployment

The site is configured for deployment to GitHub Pages or Vercel. Follow the instructions in the deployment configuration files for your chosen platform.
